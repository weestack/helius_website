About

One engineer, and you can check the work

Helius is Alexander Høgh, a staff software engineer working on Linux infrastructure, systems programming in Rust, and the parts of this trade that involve reading kernel documentation. Not an agency with a bench — when you hire Helius you get the person who writes the code.

Ten years in software, five and a half of them in production infrastructure, and I still work in it daily rather than having moved on to talking about it. That matters more than it sounds: the person diagnosing your syscall storm should have been inside a kernel this month, not in 2019.

Most of my work sits where application code meets the operating system — security agents in Rust and eBPF using LSM and kprobe hooks, hardened server fleets, performance problems that only become tractable below the application, and the infrastructure that has to hold still underneath. The eBPF work also turned into Blackbox Linux, an open-source runtime tracer I build in the open.

I write about this at length on the blog, which is where the reasoning behind most of these opinions lives. If you want to know how I think before you email me, start there.

Where that came from

  1. 2018 — 2022Freelance as Helius. Full-stack work, infrastructure and hardened hosting for 30+ clients across Denmark, Scandinavia and the US.
  2. 2022 — 2024DevOps at WEXO. 100+ dedicated Linux servers across Hetzner, Google Cloud and AWS, configured as code with Puppet and Ansible.
  3. 2024 — 2025Senior DevOps. Custom Nginx modules in Lua and OpenResty, Zero Trust networking, Kubernetes clusters, and Zabbix monitoring with alerting that meant something.
  4. 2025 — nowStaff software engineer. Kernel-level security agents in Rust and eBPF using LSM and kprobe hooks — cutting OS attack surface and mitigating CVEs at the kernel source.
