Kernel & Linux

The kernel already knows. Most security products just ask it politely

Security that runs in the kernel, not beside it.

The problem

Runtime security on Linux is mostly sold as a closed agent, licensed per host, running as root, doing something you are not allowed to read. It sees what its vendor decided to instrument, it costs more as you grow, and when it misses something you have no way to find out why. Meanwhile the primitives to do this properly have been in the kernel for years.

The approach

I write the instrumentation instead of renting it. eBPF programs attached to process lifecycle and the syscalls that actually matter, LSM and kprobe hooks that enforce rather than observe, and filtering done in the kernel so the uninteresting 99% never becomes egress or an ingest bill. The userspace side is Rust, because memory safety matters more than usual in a process that runs privileged on every host you own.

What you get

  • eBPF probes attached to the process and syscall events your threat model cares about
  • Rust userspace agent, built from source in your pipeline, no vendor binary
  • In-kernel filtering so uninteresting events never leave the kernel
  • Attack surface review: what runs, what is reachable, what can be removed
  • Structured events delivered to the telemetry pipeline you already run
  • The probe source in your repository, documented well enough to change

Tools

  • Rust
  • eBPF
  • aya
  • LSM
  • kprobes
  • seccomp

Example

probes/src/exec.bpf.c

SEC("tp_btf/sched_process_exec")
int BPF_PROG(on_exec, struct task_struct *task,
             pid_t old_pid, struct linux_binprm *bprm)
{
    struct event *e;

    /* Filter in the kernel. An event dropped here costs nothing —
       no ring buffer slot, no userspace wakeup, no egress, no bill. */
    if (!should_report(task))
        return 0;

    e = bpf_ringbuf_reserve(&events, sizeof(*e), 0);
    if (!e)
        return 0;

    e->pid  = bpf_get_current_pid_tgid() >> 32;
    e->ppid = BPF_CORE_READ(task, real_parent, tgid);
    bpf_probe_read_kernel_str(&e->comm, sizeof(e->comm),
                              BPF_CORE_READ(bprm, filename));

    bpf_ringbuf_submit(e, 0);
    return 0;
}

agent/src/main.rs

// Userspace half. The probe above fills a ring buffer; this drains it.
// Rust rather than C because this process runs privileged on every host —
// a use-after-free here is a root-level use-after-free.
let mut bpf = EbpfLoader::new()
    .btf(Btf::from_sys_fs().ok().as_ref())
    .load(include_bytes_aligned!("../../target/bpfel-unknown-none/release/probes"))?;

let program: &mut BtfTracePoint = bpf.program_mut("on_exec").unwrap().try_into()?;
program.load("sched_process_exec", &Btf::from_sys_fs()?)?;
program.attach()?;

let mut events = RingBuf::try_from(bpf.take_map("EVENTS").unwrap())?;

while let Some(item) = events.next() {
    // Zero-copy read straight out of the ring buffer. The kernel already
    // dropped everything the filter did not want, so anything arriving here
    // is worth the cycles to parse.
    let e: &Event = unsafe { &*(item.as_ptr() as *const Event) };

    sink.emit(Record {
        pid: e.pid,
        ppid: e.ppid,
        comm: str::from_utf8(&e.comm)?.trim_end_matches('\0'),
        // Process trees, not a flat firehose: the parent is resolved here so
        // whoever reads this at 3am can see what actually spawned what.
        ancestry: tree.resolve(e.ppid),
    })?;
}
